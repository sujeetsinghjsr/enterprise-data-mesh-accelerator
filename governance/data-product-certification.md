# Data Product Certification Checklist

Before publication every Data Product must pass certification.

## Engineering

- [ ] Pipeline tested
- [ ] Partitioning validated
- [ ] Delta format confirmed

## Data Quality

- [ ] Null checks
- [ ] Duplicate checks
- [ ] Business rules

## Governance

- [ ] Metadata completed
- [ ] Lineage documented
- [ ] Access approved

## Operations

- [ ] Monitoring enabled
- [ ] Alerts configured
- [ ] Documentation published
